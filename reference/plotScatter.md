# Produces page containing scatter plot plotting the first two samples from each dataset against each other for each normalization method

Produces page containing scatter plot plotting the first two samples
from each dataset against each other for each normalization method

## Usage

``` r
plotScatter(nr, currentLayout, pageno)
```

## Arguments

- nr:

  Normalyzer results object.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
