# Takes an NormalyzerStatistics instance and generates and prints a p-value histogram for each onto the viewport

Takes an NormalyzerStatistics instance and generates and prints a
p-value histogram for each onto the viewport

## Usage

``` r
plotContrastPHists(nst, jobName, currentLayout, pageno)
```

## Arguments

- nst:

  NormalyzerDE statistics object.

- jobName:

  Name of processing run.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
