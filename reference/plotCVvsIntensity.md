# Plots page displaying coefficient of variance (CV) against raw intensity for features across the performed normalizations

Plots page displaying coefficient of variance (CV) against raw intensity
for features across the performed normalizations

## Usage

``` r
plotCVvsIntensity(nr, currentLayout, pageno)
```

## Arguments

- nr:

  Normalyzer results object.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
