# Produces page showing QQ-plots for the first sample for each normalization method. This plot can be used to assess whether the data follows a normal distribution.

Produces page showing QQ-plots for the first sample for each
normalization method. This plot can be used to assess whether the data
follows a normal distribution.

## Usage

``` r
plotQQ(nr, currentLayout, pageno)
```

## Arguments

- nr:

  Normalyzer results object.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
