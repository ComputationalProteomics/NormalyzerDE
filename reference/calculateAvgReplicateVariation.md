# Calculate average variance for each feature in each condition and then calculate the average for each replicate group

Calculate average variance for each feature in each condition and then
calculate the average for each replicate group

## Usage

``` r
calculateAvgReplicateVariation(methodList, sampleReplicateGroups)
```

## Arguments

- methodList:

  List containing normalized matrices.

- sampleReplicateGroups:

  Condition header.

## Value

avgVarianceMat Matrix with average variance for each biological
condition
