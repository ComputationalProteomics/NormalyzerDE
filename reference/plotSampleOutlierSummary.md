# Write page containing sample summary of intensities, missing values and MDS plot to the viewport

Write page containing sample summary of intensities, missing values and
MDS plot to the viewport

## Usage

``` r
plotSampleOutlierSummary(nr, currentLayout, pageno)
```

## Arguments

- nr:

  Normalyzer results object.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
