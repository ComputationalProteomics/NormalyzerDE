# Generate normalization replicate variance summary by displaying CV (coefficient of variance), MAD (mean of intragroup median absolute deviation) and PEV (Pooled Estimate of Variance) as mean of intragroups

Generate normalization replicate variance summary by displaying CV
(coefficient of variance), MAD (mean of intragroup median absolute
deviation) and PEV (Pooled Estimate of Variance) as mean of intragroups

## Usage

``` r
plotReplicateVariance(nr, currentLayout, pageno)
```

## Arguments

- nr:

  Normalyzer results object.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
