# Check whether more than one sample is present

Check whether more than one sample is present

## Usage

``` r
verifyMultipleSamplesPresent(
  dataMatrix,
  groups,
  requireReplicates = TRUE,
  quiet = FALSE
)
```

## Arguments

- dataMatrix:

  Prepared dataframe.

- groups:

  Vector containing condition levels

- requireReplicates:

  By default stops processing if not all samples have replicates

## Value

None
