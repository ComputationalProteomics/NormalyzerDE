# Produces a page containing expression vs. fold-change figures (MA plots) The visualized fold is between the first sample in each group and the average of the replicate to which that sample belongs

Produces a page containing expression vs. fold-change figures (MA plots)
The visualized fold is between the first sample in each group and the
average of the replicate to which that sample belongs

## Usage

``` r
plotMA(nr, currentLayout, pageno)
```

## Arguments

- nr:

  Normalyzer results object.

- currentLayout:

  Layout used for document.

- pageno:

  Current page number.

## Value

None
